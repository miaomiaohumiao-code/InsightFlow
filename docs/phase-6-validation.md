# Phase 6：Marketing Action

入口位于 Insights 页面。选中洞察后，底部可单独生成（逐条请求）或合并生成（2–8 条共同形成一套策略）。结果包含十个必需模块，每个模块均有中文正文、推导理由和所选 Insight ID。另附验证计划、原文证据展开和 JSON 导出。

服务端读取既有 DeepSeek/OpenAI 环境变量；复用服务商选择，不新增客户端密钥。Zod 生成 JSON Schema，并在服务端与客户端验证中文、固定字段、引用范围、合并覆盖及需求人群的人口属性关键词。语义正确性仍需要人工审核，引用存在不意味着推论一定成立。

策略按分析版本、模式、所选 ID 组合保存在独立 IndexedDB。完成一套即保存；失败最多自动重试三次，用户再次点击同一模式只补齐未完成项。刷新时恢复已完成结果；页面关闭后不会继续未完成任务。保存失败提示导出。当前无跨标签页请求去重，实例内并发限制不等同于部署后的全局限流。

2026-09-18：43 项测试通过，包含额外字段、非中文、人群属性、越界引用和合并遗漏拦截；代码检查、类型检查及构建通过。浏览器完成真实单条及合并生成，刷新后两套策略仍存在。

真实 DeepSeek 用量：单条 1 次调用，输入 2416 / 输出 2177 Token；合并 1 次调用，输入 3219 / 输出 1762 Token。此前本机沙箱网络 EACCES 导致两轮失败，每轮三次未连接成功的尝试，解决网络权限后成功。金额以供应商账单为准。

合并样例命题为「稳定贴合与可靠降噪」，共同需求为减少设置与佩戴调整带来的体验中断。推荐仍属于待测试建议，不能把未验证产品能力直接用于广告承诺。
