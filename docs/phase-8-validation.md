# Phase 8：多竞品与可承接机会

支持一个自有品牌与多个竞品。竞品优势按品牌分组，每条优势必须限定一个竞品品牌组；无证据的竞品显示缺少证据，不借用其他品牌。聚合上限从所有竞品共两条提升为每个竞品最多两条、总计二十四条，避免多个竞品挤在单个列表中。

机会缺口新增 qualification：目标竞品 ID、明确需求、竞品未满足证据、自有品牌能力线索、承接理由、已有体验/潜在承接标记、可比性与待核实边界。两侧引用都必须来自 VOC，分别进行逐条语义核验。竞品侧要求明确负面或未满足体验，自有侧要求相关正面体验；潜力也不能凭空假设。普通品牌差异及共同痛点不会自动升级为机会。

组装时核验角色、品牌范围、引用真实性、方面情绪及两侧的独立支持。组合机会统一保守标为低证据强度，避免用双边提及总数制造高置信。模型对需求与能力是否真正匹配仍需要人工审核，VOC 不替代产品实测。

合格机会自动产生带 originOpportunityId 的 Insight，并展示需求型标签；选择后可直接生成 Marketing Action。营销请求携带该机会需求及包含双边承接信息的营销启示，原始证据沿用已核验引文。无需重新人工创建 Insight。

兼容：旧报告继续读取，旧机会如果没有资格证据链，则从展示机会及数量中排除并提示重新分析；不修改数据库中的历史报告。分析 Prompt 版本已升级，新的机会证据链需要重新运行分析。没有自动发起付费重分析。

验证：52 项测试通过，包括多个竞品不串证据、缺失自有证据/竞品负面证据时排除、结构兼容、去重、完整组装生成 Insight 以及缺侧证据时阻断。类型检查、ESLint 和生产构建通过。浏览器已验证旧样例中 Sony/Apple 独立分组、旧机会排除提示及无控制台错误。本阶段未再次进行真实 AI 全量分析；真实新规则产出质量仍待后续样本复核。
