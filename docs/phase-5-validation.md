# Phase 5 验收

实现独立 Insights 路由，首页已分析项目、输入页及分析完成区均可进入。复用既有 AnalysisResult，不额外调用 AI。

- 整体：VOC 数量、主题数量、高证据洞察数量、机会缺口数量；主题横向柱图、次要情感概览、痛点、需求、购买驱动与障碍。
- 条件：按来源平台、有效时间段与竞品显示对应模块。证据不足时展示原因，不编造差异。
- 卡片：需求型人群、需求与痛点、购买因素、原文及可选翻译、来源、营销启示、证据强度与营销优先级说明。
- 交互：多选、全选、清空、独立稳定排序；选择和排序按项目及分析版本保存在 Local Storage。
- 结果：优先展示最近完整分析；新运行失败不隐藏此前结果；输入变化、拆分边界待核对、空结果均有提示。
- Generate Separately / Combine Insights 在选择后显示，明确标记下一阶段开放；本阶段未实现营销行动。

指标口径：VOC 为纳入分析数，高证据洞察仅统计 Insight Cards 中 High 项，营销机会为品牌对比中的待验证机会缺口。主题支持数可重叠，不相加作为评论总数。

2026-09-18 验证：41 项自动测试通过；ESLint、TypeScript 与生产构建通过。浏览器载入既有真实样例（120 条 VOC、4 个主题、4 张洞察卡片、0 条高证据洞察、2 个机会缺口），验证多选、两种排序、刷新恢复、清空及空结果引导。390px 手机视口无横向溢出，浏览器未报告错误或警告。临时样例载入路由验收后删除。

本阶段新增 AI 调用：0。页面展示既有结果，分析解释质量仍取决于上一阶段输出与人工核对。
