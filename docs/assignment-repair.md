# 证据记录局部重试

核验响应通过结构检查后，按“结论 ID × 评论 ID”逐项验证快照、批次、来源及引文登记。只在本次服务端请求的最多三次尝试内保留有效记录；重复候选或重复评论不任选其一，缺失或无效项不补造立场。

下一次尝试只发送仍缺结果的结论和评论集合。多个结论缺失集合不同时取矩形并集，因此可能带少量已经核验过的记录；已保留结果不被覆盖。合并结果必须再次通过原始完整任务校验后才能进入持久检查点。

已有成功批次的检查点键保持不变；失败请求内的局部结果不跨请求持久化。最多三次仍不完整时继续报错，不发布不完整统计。错误现在包含缺失、重复、越界 ID 及结论上下文。

离线测试覆盖缩小重试输入、完整合并、用量累计、伪造引文和重复评论。55 项测试通过；未重新调用用户的真实数据。
