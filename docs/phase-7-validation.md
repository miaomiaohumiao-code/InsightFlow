# Phase 7：A/B 实验建议

每套已保存 Marketing Action 下提供「生成实验建议」。依据固定为该策略关联的 Insight，不会随着页面其他勾选变化悄悄改变。每套策略生成一张中文建议卡片，包含测试目标、假设、测试理由、A/B 方案、唯一核心变量、按场景推荐的指标及执行说明。

- 单变量枚举：开头吸引点、核心卖点、信息角度、行动号召、视觉风格、创意形式、广告位置、优惠传播信息。
- 两组仅存储该变量的差异内容，共同设置单独展示。A 始终标为建议基准，不冒充现有投放素材。
- 指标按广告素材、应用拉新、产品内容、电商转化分别限制；只允许一个主要指标，最多三个指标，各附理由和测量口径。
- 结果引用必须属于策略关联洞察，并能对应到策略字段；可展开原始评论及策略依据。
- 采用结构化 JSON、服务端和客户端校验、最多三次请求尝试。支持取消、失败重试、IndexedDB 保存及 Markdown 导出。缓存键包含策略及证据内容摘要，已有建议不自动重新生成。
- 只生成建议，无广告账户调用、分流、实验数据采集、胜出判断、样本量计算或显著性检验。

验收：48 项测试覆盖引用、中文结构、单变量字段、指标场景、唯一主要指标、请求体边界、存储隔离及接口；真实 DeepSeek 已成功生成建议，并在刷新后恢复。样例比较功能参数表达与持续稳定体验表达，只改变信息角度，以点击率为主要指标、转化率为辅助指标。浏览器检查桌面和 390px 手机布局，修复底部按钮挤压，无横向溢出或控制台错误。已点击建议文档导出入口。

边界：结构校验及提示约束不能完全证明建议的语义质量。实际执行前仍需审阅两组是否只改变一个变量，并核实所有产品承诺。执行说明固定要求样本量及显著性判断交给实际平台，不输出数值建议。中途关闭页面可能使成功响应来不及保存；保留页面直至完成，或导出备份。
